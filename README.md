# Mi Autocaravana — versión tabla Excel

Basada en el checklist corregido de mantenimiento (46 tareas). Muestra cinco estados: SIN HISTORIAL, REVISIÓN MANUAL, PRÓXIMO, VENCIDO y AL DÍA. Guarda datos en localStorage del navegador.

## Publicar / sustituir la versión anterior

1. En el repositorio `mi-autocaravana`, elimina los archivos anteriores o sobrescríbelos con los archivos **del interior de esta carpeta**, sin subir la carpeta contenedora.
2. Verifica que `index.html` queda en la raíz del repositorio, rama `main`.
3. GitHub Pages > Settings > Pages > Deploy from a branch > main / (root).
4. Abre `https://mdehoyoslo.github.io/mi-autocaravana/` y fuerza actualización Ctrl+F5 si sigues viendo la versión antigua.

**IMPORTANTE**: Los registros de esta versión se almacenan en el navegador del dispositivo. No hay sincronización entre dispositivos. Antes de borrar datos o limpiar el navegador, descarga una copia JSON desde Resumen y configuración. Si habías introducido datos en la versión anterior, expórtalos desde la anterior antes de sustituirla; no se migran automáticamente.
